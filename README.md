# Soil Fertilizer Classification Model
An AI-based machine learning model for predicting the most suitable fertilizer based on soil and environmental conditions.

## Project Overview
This project uses machine learning techniques to classify and recommend fertilizers according to several agricultural parameters such as:
- Soil type
- Crop type
- Temperature
- Moisture
- Rainfall
- pH level
- Nitrogen
- Phosphorous
- Potassium
- Carbon content

The model was developed and trained using Python in Google Colab with ensemble learning approaches and model optimization techniques.

---

## Features
- Data preprocessing and cleaning
- Exploratory Data Analysis (EDA)
- Data visualization
- Label encoding
- Ensemble machine learning models
- Hyperparameter tuning using GridSearchCV
- K-Fold cross validation
- Model evaluation and comparison
- SHAP-based model interpretation
- Fertilizer recommendation function

## Machine Learning Models
The project compares several models, including:
- Decision Tree
- Random Forest
- XGBoost

The final optimized model uses tuned XGBoost parameters for better prediction accuracy and stability.
